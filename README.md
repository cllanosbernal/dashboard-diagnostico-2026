# Dashboard Diagnóstico 2026

Sitio estático para publicar el dashboard de diagnóstico en GitHub Pages.

## Publicación
Este repositorio está preparado para servir `index.html` desde la rama `main`.

## Vercel
El sitio está desplegado en Vercel:

- Producción: https://dashboard-diagnostico-2026.vercel.app
- Proyecto: `dashboard-diagnostico-2026`

Si se desea activar despliegues automáticos desde GitHub, la integración de Vercel debe tener acceso al repositorio `cllanosbernal/dashboard-diagnostico-2026`.
